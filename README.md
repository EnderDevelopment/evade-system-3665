# Evade System

A temporary invincibility system for FiveM players.

## Features

- Temporary invincibility for players
- Cooldown system to prevent abuse
- Cost to activate the evade system

## Requirements

- FiveM server with ESX Legacy framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Import the database.sql file into your MySQL database
4. Add `start evade-system` to your server.cfg file

## Usage

Players can activate the evade system by using a command or menu option. The cost is deducted from their bank account.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the evade time, cooldown time, and price.
